# Voltio Banking Platform

Voltio is a full-stack digital banking application with a React frontend, a Spring Boot banking API, and a separately deployable GIC-rates MCP service used by the savings chatbot.

## Start here

- New to the repository? Read the [project architecture overview](Documentation/onboarding/project-overview/architecture-overview.md).
- Looking to run or test the project locally? Follow [developer setup](SETUP.md).
- Exploring individual features? Browse the [feature specifications](specs/).

The overview maps the main source areas and explains how the browser, API, data stores, and chatbot integrations work together.
